# CodingEdu 발표 대본

## 발표 톤

- 전체 흐름은 `프로젝트 개요 → 기술 스택 → 실제 화면 기능 설명` 순서로 진행합니다.
- 슬라이드 문장을 그대로 읽기보다, 핵심만 자연스럽게 설명하는 방식이 좋습니다.
- 실제 화면 설명 부분에서는 화면을 가리키면서 기능을 짧게 연결합니다.

---

## 0. 표지

안녕하세요. 저희는 `개발의 정석` 팀입니다.  
저희가 발표할 프로젝트는 `CodingEdu`라는 코딩 스터디 웹사이트입니다.

CodingEdu는 코딩을 처음 배우는 사용자가 강의를 듣고, 퀴즈로 복습하고, 커뮤니티에서 질문과 답변을 이어갈 수 있도록 만든 온라인 학습 플랫폼입니다.

이번 발표는 크게 세 가지 흐름으로 진행하겠습니다.  
첫 번째는 프로젝트 개요와 설명, 두 번째는 사용한 기술 스택, 세 번째는 실제 화면을 보면서 주요 기능을 설명드리겠습니다.

---

## 1. 프로젝트 개요

먼저 프로젝트 개요입니다.  
저희는 프로그래밍을 처음 배우는 사람들이 학습 자료는 많이 접하지만, 어떤 순서로 공부해야 할지 어려움을 느낀다는 점에 주목했습니다.

그래서 단순히 강의 영상만 보여주는 사이트가 아니라, 강의 시청 이후에 퀴즈로 복습하고, 학습 기록을 확인하고, 커뮤니티에서 질문까지 이어갈 수 있는 구조를 만들고자 했습니다.

CodingEdu의 목표는 초보 학습자가 학습 흐름을 잃지 않고 꾸준히 공부할 수 있도록 돕는 것입니다.

---

## 2. 서비스 흐름

서비스의 기본 흐름은 네 단계입니다.

먼저 사용자가 HTML, CSS, JavaScript 같은 강의를 선택합니다.  
그 다음 유튜브 기반 강의 영상을 보면서 학습을 진행하고, 필요한 경우 개인 노트를 작성할 수 있습니다.

강의를 들은 뒤에는 퀴즈를 통해 학습 내용을 복습합니다.  
퀴즈 결과는 정답률이나 포인트 같은 형태로 확인할 수 있고, 이후 커뮤니티에서 질문이나 답변을 하면서 학습을 이어갈 수 있습니다.

즉, CodingEdu는 `강의 선택 → 영상 학습 → 퀴즈 복습 → 커뮤니티 활동`으로 이어지는 학습 흐름을 중심으로 설계했습니다.

---

## 3. 기술 스택

다음은 사용한 기술 스택입니다.

백엔드는 `Java 21`과 `Spring Boot 3.4.1`을 사용했습니다.  
페이지 요청과 기능 처리는 Spring MVC 구조로 구현했고, 화면은 `Thymeleaf`를 사용해 서버 렌더링 방식으로 구성했습니다.

데이터베이스 연동은 `Spring Data JPA`를 사용했습니다.  
회원 정보, 강의 진도, 퀴즈 결과, 게시글과 댓글 같은 데이터를 DB에 저장하고 관리하도록 했습니다.

보안 쪽에서는 `Spring Security`를 사용해서 로그인, 권한 처리, 비밀번호 암호화, CSRF 보호를 적용했습니다.

정리하면, CodingEdu는 Spring Boot 기반의 서버 렌더링 웹 서비스이고, 회원별 학습 기록과 활동 데이터를 DB에 저장한 뒤 화면에서 바로 보여주는 구조입니다.

---

## 4. 실제 화면 - 홈

이제 실제 화면을 기준으로 기능을 설명드리겠습니다.  
먼저 홈 화면입니다.

홈 화면은 사용자가 처음 들어왔을 때 서비스의 목적을 바로 이해할 수 있도록 구성했습니다.  
상단에는 메뉴가 있고, 중앙에는 CodingEdu의 핵심 문구와 강의 시작 버튼이 있습니다.

아래쪽에는 추천 강의 카드와 학습 현황 카드가 배치되어 있습니다.  
사용자는 홈 화면에서 현재 어떤 강의를 들을 수 있는지, 전체 학습 흐름이 어떻게 구성되어 있는지 빠르게 확인할 수 있습니다.

발표 시연에서는 홈 화면에서 강의 메뉴로 이동하는 흐름을 보여드리겠습니다.

---

## 5. 실제 화면 - 강의

다음은 강의 화면입니다.

강의 페이지에서는 HTML, CSS, JavaScript 강의를 확인할 수 있습니다.  
강의 콘텐츠는 입문자가 접근하기 쉬운 생활코딩 강의를 중심으로 구성했습니다.

강의 목록에서는 강의 제목, 설명, 진행률을 볼 수 있고, 강의 상세 화면으로 들어가면 유튜브 영상이 재생됩니다.  
또한 레슨별 완료 처리를 통해 진도율이 반영되도록 했고, 사용자가 학습 내용을 정리할 수 있도록 개인 노트 기능도 구현했습니다.

이 기능의 핵심은 단순히 영상을 보여주는 것이 아니라, 사용자가 어디까지 학습했는지 기록하고 이어서 공부할 수 있게 만드는 것입니다.

---

## 6. 실제 화면 - 퀴즈

다음은 퀴즈 화면입니다.

퀴즈 기능은 강의를 들은 뒤 학습 내용을 바로 복습할 수 있도록 만든 기능입니다.  
사용자는 주제와 난이도에 따라 퀴즈를 선택하고 문제를 풀 수 있습니다.

문제를 제출하면 자동으로 채점이 이루어지고, 점수와 정답 여부, 해설을 확인할 수 있습니다.  
또한 총 퀴즈 횟수, 정답률, 연속 완료, 획득 포인트 같은 통계 정보를 카드 형태로 보여주도록 구성했습니다.

이를 통해 사용자는 단순히 강의를 듣는 것에서 끝나지 않고, 자신이 내용을 이해했는지 바로 확인할 수 있습니다.

---

## 7. 실제 화면 - 커뮤니티

다음은 커뮤니티 화면입니다.

커뮤니티는 사용자가 혼자 공부하다가 막히는 부분을 질문하거나, 다른 사용자의 글에 댓글로 답변할 수 있도록 만든 공간입니다.

게시글 작성, 조회, 수정, 삭제 기능을 구현했고, 댓글과 알림 기능도 함께 구성했습니다.  
또한 카테고리 탭과 검색 기능을 통해 원하는 게시글을 더 쉽게 찾을 수 있도록 했습니다.

오른쪽에는 인기 태그나 활동 정보 같은 보조 영역을 배치해서 커뮤니티가 단순 게시판이 아니라 학습자 활동 공간처럼 보이도록 구성했습니다.

---

## 8. 실제 화면 - 마이페이지와 관리자

다음은 마이페이지와 관리자 기능입니다.

마이페이지에서는 사용자의 학습 기록과 활동 내역을 확인할 수 있습니다.  
예를 들어 어떤 강의를 진행했는지, 퀴즈 결과가 어떻게 나왔는지, 커뮤니티 활동은 어떤 것이 있는지 확인할 수 있습니다.

관리자 페이지에서는 사용자 권한 관리, 퀴즈와 문제 관리, 챌린지 관리가 가능하도록 구성했습니다.  
즉, 일반 사용자의 학습 흐름뿐만 아니라 서비스 운영에 필요한 관리 기능도 함께 구현했습니다.

이 부분을 통해 CodingEdu가 단순한 정적 페이지가 아니라, 실제 사용자와 관리자가 함께 사용할 수 있는 웹 서비스 구조를 갖추고 있다는 점을 보여줄 수 있습니다.

---

## 9. 마무리

마지막으로 정리하겠습니다.

CodingEdu는 코딩 입문자가 강의를 듣고, 퀴즈로 복습하고, 커뮤니티에서 질문하며 학습을 이어갈 수 있도록 만든 코딩 스터디 웹사이트입니다.

이번 프로젝트를 통해 회원 인증, 강의 진도 관리, 퀴즈 자동 채점, 커뮤니티, 관리자 기능까지 웹 서비스의 기본 흐름을 구현해볼 수 있었습니다.

향후에는 실습 코드 에디터, 추천 강의 기능, 배지나 레벨 같은 게이미피케이션 요소를 더 강화하면 학습 동기를 높일 수 있을 것 같습니다.

이상으로 발표를 마치겠습니다. 감사합니다.

---

## 실제 시연 순서

1. 홈 화면에서 서비스 소개 확인
2. 강의 메뉴 진입
3. 강의 목록에서 JavaScript 또는 HTML 강의 선택
4. 강의 상세 화면에서 영상 재생과 진도/노트 설명
5. 퀴즈 메뉴 진입 후 퀴즈 목록과 통계 카드 설명
6. 커뮤니티 메뉴 진입 후 게시글 목록, 검색, 댓글 기능 설명
7. 가능하면 마이페이지 또는 관리자 페이지에서 기록/관리 기능 설명

## 짧은 마무리 멘트

CodingEdu는 강의, 퀴즈, 커뮤니티를 따로 분리하지 않고 하나의 학습 흐름으로 연결한 점이 특징입니다.  
초보자가 강의를 듣고 바로 복습하고, 막히는 부분은 커뮤니티에서 이어갈 수 있도록 구성했습니다.
